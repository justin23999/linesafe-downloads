# LineSafe v1.1.0

Windows release of LineSafe.

## What's new

- App-wide appearance themes
- Default appearance mode
- Solid colour themes:
  - White
  - Soft Blue
  - Soft Green
  - Warm Grey
  - Cream
  - Light Lavender

## Core features

- Pipeline survey data entry
- HI / RL calculations
- Ground and Pipe Crown profiles
- Pipe Cover workflow
- Dynamic custom profile lines
- Point annotations
- Obstacles
- Pipe fittings
- Profile references
- Project save and reopen
- Excel import/export
- PDF longitudinal profile export
- AutoCAD DXF export

## Windows downloads

### Recommended
`LineSafe-Setup-1.1.0.exe`

Normal Windows installer.

### Portable
`LineSafe-Portable-1.1.0-Windows-x64.zip`

Portable version that can be extracted and run without installing.
